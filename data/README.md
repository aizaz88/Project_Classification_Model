# Dataset

Dataset is NOT stored in Git (about 800 MB). Download it with:

    python src/download_data.py

Source: "Dog and Cat Classification Dataset" (Kaggle, bhavikjikadara) - 25,000 JPEG images
in two folders: `PetImages/Cat` and `PetImages/Dog`.
https://www.kaggle.com/datasets/bhavikjikadara/dog-and-cat-classification-dataset
